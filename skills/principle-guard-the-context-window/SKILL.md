# コンテキストウィンドウを守る（Guard the Context Window）

**なぜ**: コンテキストの超過は推論の質を下げ、圧縮の痕跡を生み、進行を止める。

- バルク（大きな出力・長いファイル・繰り返しの読み込み・ファンアウト計画）はサブエージェントへ回し、本スレッドには要約だけ残す。
- フェーズの規模と範囲を区切る（フェーズごとのファイル数、ターン予算、機構のコストを見積もる）。
