# Autonomous run

**あなたが終了条件を所有する。done を定義し、止まらずにそこまで駆動する。**

1. 終了条件を、最初の反復の前にチェック可能な述語として宣言する（テスト緑、repro 解消、全 N PR マージ、pixel-diff 0）。
2. ウェイク機構を選ぶ。イベント（CI・マージ・ref 進行）を見張る必要があれば watcher サブエージェントが知らせる。イベントが無ければ定時ハートビート。実装は `hc wait --children any --timeout <N>`（`docs/loop-mechanism.md` 参照）。
3. 各反復で、証拠が正当化する最小の変更をし、述語に対して検証し、進んだらコミット、進まなければ捨てる。「効くかも」の belt-and-suspenders は残さず revert する。作業は `principle-sequence-verifiable-units` で並べ、各単位を検証してから次へ。
4. 途中発見（壊れたスキル・関連バグ・flaky verifier・ツール障害・孤児フォローアップ・直せるドリフト）は自分で処理する。別 PR に出す。可逆な仕事を人に預けたり「聞く」をしない。表面化させるのは不可逆な行動、実験で決まらないプロダクト判断、本当の行き止まりだけ。述語を主軸に保ち、各サイドフィックスの後はそこへ戻る。
5. 毎反復を `show-me-your-work` でチェックポイントする（何を変えたか、述語が動いたか）。
6. 述語成立で停止する。plateau は停止ではない。アプローチを変えて押し通す。本当の行き止まりは表面化し、述語を緩めて勝ちにしない。

**返信:** 終了条件、反復回数、着地したもの、捨てたもの、最終的な述語の状態。
