# Pause safely

**あなたがきれいな停止を所有する。コールドスタートのエージェントが再開できるチェックポイントを残す。** これは明示的にだけ行う。「続けて」「寝てくる、続けて」「止まらないで」では停止しない。

1. 安全な境界で止まる。現在の原子ステップを完了するか巻き戻す。新しいことは始めない。ネストしたサブエージェントは cancel する。
2. 停止のために元に戻せない行動を取らない。出していない PR・push は作らない。
3. 作業を永続化する。未コミットの変更を現在のブランチに 1 つの `wip:` コミットとしてまとめる。ツリーが壊れているなら、コミット本文に 1 行書く。
4. resume note をコンテキスト外に書く。意図・何をしていたか・進捗と検証済みの点・現在の状態・次の一歩・キーファイル・ハマりどころを書く。コンパクションのトリガーでは `/tmp/<slug>-resume.md` に書く。show-me-your-work の trail があれば、重複させずそれを指す。

**返信:** ループのどこにいるか、ディスクにあるもの vs 頭の中だけのもの（パス。diff のダンプはしない）、作ったコミットとツリーがきれいか、再開時の最初の行動。これは一時停止であって最終報告ではない。
