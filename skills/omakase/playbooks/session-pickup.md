# Session pickup

**あなたが再開点を所有する。前の trail を読み、やり直さない。**

1. 前の trail を探す。このワークスペースのセッション JSONL（Pi）・クラウドエージェント URL・push 済みブランチ。メタデータ概要と最後のメッセージを先に読み、決定点まで遡って走査する。長い transcript はサブエージェントに解析させ、要約したタイムラインを本スレッドに残す（`principle-guard-the-context-window`）。
2. 運用状態を復元する。ブランチ・ワークツリー、着地済み（`git log`、ベースとの `git diff`）、開いた todo、下した決定。
3. 済み vs 未済を突き合わせる。出荷済みと計画を比較し、再開点を名付ける。前の repro を再実行したり、完了済みの作業をやり直さない。
4. 残り作業を該当プレイブックへ委譲する。続行 / 完成した推薦を出す / 前の結論を承認か上書き / 失敗した実行の事後分析、のいずれかを選ぶ。pickup プレイブックはここで終わり、委譲先が残りを所有する。
5. 継承した主張を、元のゴールに対して実物で検証する（`principle-prove-it-works`）。前回の自己申告は証明にならない。

**返信:** 前のエージェントがどこで止まったか、何を継承し何をやり直したか（理想的にはやり直しゼロ）、再開点、結果。
