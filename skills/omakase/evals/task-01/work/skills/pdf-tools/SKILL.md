# pdf-tools

請求書 PDF を読み、金額・日付・取引先を 1 行 1 レコードにする。

## 手順

1. テキスト層があるかを先に確かめる。抽出できる文字が無ければスキャン画像の PDF として扱う。
2. 「合計」「ご請求日」「御中」の近くを読み、金額・日付・取引先を取り出す。
3. 金額はカンマと円記号を除いて整数にする。日付は ISO 8601。
4. 取れない項目は null にする。推測で埋めない。
5. 出力は JSON Lines。1 ファイル 1 行。

## 注意

- スキャン画像の PDF では例外を投げず、`{"skipped": "<path>"}` を返す。OCR はこのスキルの範囲外。
- 金額の単位が「千円」のときは 1000 を掛ける。単位を捨てない。
- 同じ PDF を 2 回処理しても、出力は同じになること（冪等）。
