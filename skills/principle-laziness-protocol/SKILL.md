# 怠惰プロトコル（Laziness Protocol）

- **決定を一元化する**。同じ選択を複数箇所で繰り返さない。1 つの真実源の背後に置き、結果を単純なフラグで渡す。
- **差分を最小にする**。問題を解く最小の変更を書く。行数が少ないことが「エレガント」なボイラープレートに勝る。
