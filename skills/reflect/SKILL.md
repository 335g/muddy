# Reflect

現在の会話から永続的な学びを採掘し、スキル編集へ振り分ける。

「reflect」「/reflect」と言われたら呼ぶ。些末・主題から外れた・既存スキルが正しく従われている会話では省略する。一回きりは学びではない。

## 1. 会話 transcript を特定する

このワークスペースのセッション JSONL（Pi）から、この会話の transcript を探す。開いた最初のユーザープロンプトが一致するファイルを取る。無ければ、セッションのタイトな要約を代わりに使う。

## 2. 3 つのレビューを並列に立てる

`subagent-ctl` の 6 動詞で並列に起動し、各レビューに transcript のパス（または要約）を渡す。

| レンズ | ロール | 見るもの |
|--------|--------|----------|
| 判定 | `judgment` | 判断の質、決定の妥当性 |
| ツール | `code` | ツールの使い方、作業効率 |
| 発散 | `judgment`（別ファミリー） | 見落とし、別の道 |

各レビューは発見のリストを返す。

## 3. 統合する

1 つの統合者（`judgment` ロール）が各レビューの出力を検証し、Accepted / Rejected / Backlog に仕分ける。

## 4. 構造的強制のチェック

Accepted のうち、lint・スクリプト・メタデータ・ランタイムチェックの方が確実に強制できるものは Backlog へ移す。

## 5. 適用（承認を待つ）

統合者の Accepted / Rejected / Backlog を提示し、適用前に明示的な承認を待つ。スキル変更は将来の全エージェントに影響する。自動適用しない。

Backlog 項目は待たずに backlog へ記録する。Accepted だけが承認を待つ。

## 6. 要約

- 適用した編集: スキルパス + 何を変えたか 1 行
- 新規スキル: 1 行（稀）
- Backlog: 1 行ずつ
- 却下: 1 行ずつ + 理由
