# 検証可能な単位で進める（Sequence Verifiable Units）

作業を小さな単位の列に分け、各単位が検証可能な状態で終わるようにし、現在の単位が緑になるまで先へ進まない。

**実行**。掃引・マイグレーション・類似編集の連続では、各変更を次の変更の前に検証する。各単位は before/after の括弧（既知の良状態 → 1 変更 → 検査 → 次へ）。先にきれいな trunk へ rebase し、各検査が本物のベースラインに対して測れるようにする。

**納品**。コミット/PR はストーリーが証明される順に積む。基本形は「失敗テストを先に、修正をその上に」。他に「減算を先に、再形成をその上」「ベースライン取得を先に、施術をその上」。
